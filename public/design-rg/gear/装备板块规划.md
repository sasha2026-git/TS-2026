## 一、关键词矩阵

竞争度判断依据：中文搜索结果中知乎攻略/买购榜/什么值得买占据头部 = 内容型流量入口成熟但竞争中等；垂直深度测评（含真实价格区间 + 国际购买渠道）仍是空白点。

### 1. 女款网球裙（P0 · 流量最大）
- 核心词：网球裙
- 长尾词：网球裙推荐 / 网球裙怎么选 / 网球裙穿搭日常 / 大码网球裙 / 网球裙哪个牌子好
- 调研发现：买购、休闲君、smzdm 均有榜单（迪卡侬、蕉下、耐克、斐乐、Lululemon 为常见款）；"网球风"日常穿搭是社媒热门话题，搜索量高
- 内容形式：选购指南（流量入口）+ 单品种草（转化）
- 优先级：**P0**

### 2. 网球拍（P0 · 客单价最高）
- 核心词：网球拍推荐
- 长尾词：网球拍怎么选 / 新手网球拍推荐 / 进阶网球拍 / 网球拍磅数怎么选 / Wilson Clash 值得买吗
- 调研发现：知乎大量攻略，但多为国产品牌软文（川崎/匹克），国际品牌（Wilson/Head/Babolat）的深度中文对比测评稀缺；客单价 ¥600–2500，佣金收益主力
- 内容形式：选购指南 + 对比测评 + 单品种草
- 优先级：**P0**

### 3. 网球鞋（P0 · 刚需复购）
- 核心词：网球鞋
- 长尾词：网球鞋怎么选 / 网球鞋和跑步鞋区别 / 红土网球鞋推荐 / 宽楦网球鞋 / 女款网球鞋推荐
- 调研发现：Extrabux/知乎攻略覆盖品牌（Asics/Nike/Adidas/Yonex/Head），按场地（硬地/红土/草地）细分内容是差异化机会
- 内容形式：选购指南（按场地细分）+ 对比测评
- 优先级：**P0**

### 4. 网球（P1 · 低客单高频复购）
- 核心词：网球哪个牌子好
- 长尾词：练习球和比赛球区别 / 网球气压球和无气压球 / 训练用球推荐 / 网球一桶多少个 / 红土用什么网球
- 内容形式：选购指南（一篇长青文即可）
- 优先级：**P1**

### 5. 网球线（P1 · 进阶用户精准流量）
- 核心词：网球线推荐
- 长尾词：聚酯线和羊肠线区别 / 网球线磅数推荐 / Luxilon ALU Power 怎么样 / 网球线多久换一次 / 复合线硬线搭配
- 调研发现：知乎/贴吧讨论热（ALU Power 约 ¥90–250/RPM 系列常见），但系统性中文攻略少；用户复购率高（断线即换）
- 内容形式：选购指南 + 单品种草
- 优先级：**P1**

### 6. 男款网球服（P2）
- 核心词：网球服男
- 长尾词：男款网球套装推荐 / 网球服和跑步服区别 / 温网白色球衣要求 / 网球polo衫推荐 / 费德勒同款网球服
- 内容形式：单品种草为主
- 优先级：**P2**

### 7. 网球包（P2）
- 核心词：网球包
- 长尾词：网球拍包推荐 / 单肩包和双肩背包怎么选 / 网球包几支装 / 大容量网球包 / 网球通勤包
- 内容形式：选购指南 + 单品种草
- 优先级：**P2**

### 8. 网球发球机（P1 · 超高客单，低流量高转化）
- 核心词：网球发球机
- 长尾词：家用网球发球机推荐 / 网球发球机多少钱 / 便携网球发球机 / 发球机值不值得买 / Spinshot 怎么样
- 调研发现：中文内容极少；Spinshot 官网确认有 Affiliate Program（spinshotsports.com），Plus-2 起价 $1,999；京东亦有国产低价款（¥1k–3k）；一单佣金可抵数十单服装
- 内容形式：深度选购指南 + 品牌对比（Spinshot / 国产 PT 等）
- 优先级：**P1**

### 9. 网球运动太阳镜（P2）
- 核心词：网球太阳镜
- 长尾词：运动太阳镜推荐 / 打网球戴什么墨镜 / Oakley 网球眼镜 / 防紫外线运动眼镜 / 网球眼镜防紫外线
- 内容形式：单品种草（Oakley/Rudy Project 等）
- 优先级：**P2**

### 10. 其他配件：握把胶/护腕/避震器（P1 · 兜底转化件）
- 核心词：网球配件
- 长尾词：握把胶多久换一次 / 薄握把胶和厚握把胶 / 网球避震器有用吗 / 护腕推荐 / 网球手胶怎么缠
- 内容形式：一篇"新手配件清单"综合指南 + 各配件单品短文
- 优先级：**P1**（流量小但决策快、转化率高，是内容内链的兜底件）
