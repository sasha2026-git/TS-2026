## 合集定位

网球明星的「装备 + 时尚版图」是本站最有点击体质的内容线：把每位球星的服装、球拍球鞋、珠宝腕表、代言全景拆成**可购清单**，每件同款附购买渠道（联盟链接占位 `[AFF:amazon:…]` + 国内/官网直购指引）。叙事模板沿用 `osaka.html`：

> Hero 个性叙事 → 版图导览（mono 标签）→ 分品类清单（spec-grid：品牌/系列/价格/渠道）→ 同款购买地图 → 风格关键词总结 → FAQ

内容纪律：**代言逐个核实**；佩戴 vs 官宣代言严格区分；查不到的条目不写或标「待核实」；联盟金额一律标「据报道」。每人一个 accent 主色（对比度 ≥4.5:1）。

## 更新机制

以下事件任一发生即触发对应稿件更新（更新对应章节 + FAQ + 代言全景，不重写全篇）：

1. **大满贯夺冠** → 更新夺冠场景条目（如腕表/装备特写）与 hero meta 数字
2. **新代言官宣** → 对应品牌条目从「待核实」转正，或代言全景新增条目
3. **合约终止/品牌变动** → 移入「已成历史」注记（参考费德勒稿的 Credit Suisse 处理）
4. **签名款/联名零售化** → 新增「可购买」条目
5. 每年美网后（9–10 月）做一次**全篇年度复查**：价格、合约报道口径、死链
6. **新增球员** → 建页 → 更新 `index.html` 卡片与篇数 → 更新本 README 表格

- 价格一律来自搜索结果并标注整理时间与「以官网为准」

- 每篇过 `/root/.openclaw/skills/网站审美/scripts/impeccable detect` 0 anti-patterns 后归档
- 内部反链：球拍/球鞋条目 → `../球拍/`、`../女装/` 等子合集首页；本合集内各篇互链；顶部导航回合集首页
